# SAP SD e logística de varejo

Eu descrevo o atendimento de pedidos desde a criação até a entrega, considerando operações de loja, estoque e integração entre SAP SD e MM.

O arquivo `cenarios.json` registra APU (retirada em loja), SFS (envio a partir da loja) e IDL (logística de distribuição de entrada), com etapas de conferência para cada fluxo. É documentação funcional, não configuração SAP.
