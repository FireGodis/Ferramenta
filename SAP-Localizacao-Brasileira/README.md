# Localização brasileira e tributos SAP

Eu organizei uma matriz de estudo para localização fiscal brasileira em SAP MM e FI. O arquivo lista tributos, códigos e tópicos de parametrização a avaliar conforme o cenário e a legislação aplicável.

Incluo J1BTAX, TAXBRA, TAXBRJ, procedimentos fiscais, CFOP, CST, IVA, ICMS, ICMS-ST, ISS, PIS, COFINS, IPI, IBS e CBS. Também registro SAP DRC e integrações com Thomson Reuters, Synchro e Avalara.

Para projetos, separo temas de implementação, rollout, Greenfield e Brownfield, com referências a SAP Activate e ASAP. Esta matriz é didática; não é parecer tributário nem customizing.
