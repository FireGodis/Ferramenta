# SAP FI/CO e interfaces

Neste estudo eu mapeio contas a receber, contabilização de receitas, determinação de contas e integrações FI-SD e FI-MM. Também registro pontos de análise para interfaces com aplicações não SAP.

Incluo User Exits e WebDynpro como tópicos de extensibilidade e interface. O artefato `integracoes.json` representa eventos funcionais e não é transportável para SAP.
